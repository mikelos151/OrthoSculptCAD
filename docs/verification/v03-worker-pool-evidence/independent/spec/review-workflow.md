# Readonly pool review recipe

1. Freeze actual source/test/G1a/plan SHA before execution.
2. Compile actual modules with installed tsc and bounded heap into owned scratch.
3. Exercise opaque handles, reentrant STARTING/dispose, failure-held charge and independent graph counters through actual public APIs; label EventTarget stand-ins UNIT.
4. Audit raw author RED/GREEN commands, unchanged pair test bytes, and AST drift through final tests. Immediate GREEN is coverage, not new TDD.
5. Recompute native chronology and source/served SHA from completed data without replaying browser concurrently. Never transfer isolated pool evidence to global App cap or RSS.
6. Recheck SHA/HEAD/index and write fail-closed JSON plus artifact manifest.
